# CRM — Telegram-бот с локальной моделью и MCP

Учебный каталог электроники. В проекте два компонента: `bot/` (Telegram, локальный агент Ollama, MCP-клиент) и `mcp_server/` (настоящий MCP-сервер, SQLite, поиск и источники цен). MCP-сервер запускается ботом как отдельный локальный процесс через стандартный транспорт stdio. Для его использования сетевой порт не открывается.

## Важно перед запуском

* Первый человек, который отправит `/start` **в личном чате**, становится единственным администратором. Никакой предварительной регистрации нет. Запустите бота и сразу отправьте `/start` сами; не публикуйте имя бота до этого. Если у бота уже есть входящие сообщения, в очереди может оказаться чужой `/start`. Лучше использовать нового бота. Роль сохраняется в SQLite. Групповые чаты не участвуют в назначении администратора.
* Начальные товары и цены демонстрационные. Они не являются проверенным наличием, реальными характеристиками или действующими предложениями. Исправьте или удалите их перед использованием.
* Модель и база работают локально. Telegram и подключённые источники цен используют интернет. Переписка с ботом проходит через Telegram.
* Подключены два источника реальных цен: НИКС и KNS. При несовпадении характеристик, отсутствии товара или недоступности сайта предложений может быть меньше двух.

## Установка и запуск в Windows

1. Нужны Python 3.12+, установленный Ollama и Telegram-бот с токеном от BotFather.
2. Откройте PowerShell в папке `MCP`. Если окружение ещё не создано:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. В файле `.env` укажите `TELEGRAM_BOT_TOKEN=токен`. Не передавайте токен другим людям и не публикуйте `.env`. Значения по умолчанию также есть в `.env.example`. Если токен будет скомпрометирован, перевыпустите его через BotFather.
4. Запустите Ollama и проверьте `ollama list`. По умолчанию используется `qwen3:8b`; модель можно изменить в `.env`, например на `qwen2.5:7b` или `llama3.2:3b`. Качество вызова инструментов у моделей различается.
5. Запустите:

   ```powershell
   .\.venv\Scripts\python.exe -m bot.bot
   ```

6. Сразу откройте личный чат с вашим ботом и отправьте `/start`. Оставьте окно программы открытым. Для остановки нажмите `Ctrl+C`.

База `mcp_server/products.db` создаётся при первом запуске. Повторный запуск не перезаписывает каталог. Чтобы сохранить данные, копируйте базу, когда бот остановлен. Для сброса администратора остановите бота, сохраните резервную копию и удалите запись `admin_id` из таблицы `settings` с помощью SQLite; следующий личный `/start` назначит администратора. Удаление всей базы удалит и товары.

## Работа с ботом

Свободный текст обрабатывает локальный продавец-консультант. Кнопки остаются дополнительным способом навигации. Пример разговора:

Запросы наличия и ассортимента читают SQLite через MCP напрямую и не требуют генерации LLM. «Телефоны есть?», «Что у вас есть?», «Пришли каталог всех устройств», «Пришли таблицу ассортимента» возвращают фактические названия и цены, включая все категории. Они не ограничиваются тремя рекомендациями и не наследуют прежний бюджет подбора. Большой каталог разбивается на страницы по 20 товаров; команды «дальше» и «назад» переключают страницы. Ошибка чтения каталога сообщается отдельно и не трактуется как отсутствие товаров. Обычная консультация получает свежий состав каталога, а неподтверждённые утверждения модели о наличии заменяются ответом по данным базы.

* «Привет, нужен ноутбук для учёбы и фильмов» — бот уточнит бюджет.
* «До 90 тысяч, не меньше 16 ГБ оперативной памяти» — подберёт варианты из SQLite.
* «Сравни первый и второй, что лучше по экрану?» — сравнит именно показанные модели.
* «А подешевле?» — сохранит категорию, бюджет и подтверждённые требования и покажет самый доступный подходящий вариант.
* «Покажи все характеристики первого» — прочитает актуальную карточку.
* «Сравни цену этой модели с конкурентами» — вызовет сравнение без нажатия кнопки.

Бюджет и обязательные характеристики подтверждаются сообщениями клиента: модель не может назначить их сама. Если точных совпадений нет, отличия показываются явно. `/reset` начинает новый подбор; `/start` также очищает контекст разговора, сохраняя администратора и товары. Диалоги разных клиентов разделены, хранятся в памяти процесса и очищаются после перезапуска или периода неактивности. Для технических характеристик, цен и наличия модель использует MCP-инструменты; запись остаётся в административном меню с подтверждением. Заказы и оплата не подключены.

Каталог открывается кнопкой, товар — нажатием на его название. В карточке доступны похожие товары и сравнение цен. Можно написать «ноутбук», «телефон до 50000 рублей с 256 ГБ памяти», «найди похожее на iPhone 13». Для свободного текста модель выбирает инструменты; результаты каталога формируются из базы. Нечёткий подбор ориентировочный: проверяйте показанные различия и пропущенные характеристики. Бот не рассчитывает реальную производительность техники.

Администратор открывает «Управление товарами» → «Добавить товар» либо карточку товара → «Изменить» / «Удалить». Бот показывает форму и просит подтверждение. Товар редактируется по отдельным полям; поле характеристик заменяет весь перечень. `/cancel` отменяет операцию. Изменения и удаления записываются в таблицу `audit`. Языковая модель получает только инструменты чтения; операции записи доступны через административный интерфейс.

## Сравнение с конкурентами

Источники уже записаны в `mcp_server/sources.json` и работают без платных API и регистрации:

* **НИКС**: [правила использования каталога](https://www.nix.ru/copyrights_trademarks.html) разрешают всем использовать фрагменты при наличии ссылки на источник после фрагмента. Адаптер находит карточки через публичный каталог категории/производителя и читает цену, наличие и характеристики из карточки. Ссылка на НИКС присутствует в сообщении сравнения.
* **KNS**: магазин публикует [скачиваемый прайс](https://www.kns.ru/price.html) и публичный каталог. Для поиска карточек используется его открытая карта сайта; чтение карточек допускается текущим `robots.txt`. Рублёвая цена берётся из основного блока карточки, без клубной скидки. Долларовые значения прайса не конвертируются. Основание подключения — публичное предоставление цен и разрешённый роботам доступ, а не отдельная лицензия на перепубликацию всего каталога.

Перед сетевым чтением адаптер проверяет `robots.txt`; отказ, CAPTCHA, перенаправление и требование входа останавливают чтение. Запросы к одному магазину разделены интервалом не меньше 1,1 секунды. Карты сайта кэшируются 24 часа, страницы категорий НИКС — час, цены карточек — 15 минут. Дата в сообщении относится к фактическому чтению карточки, включая попадание в кэш. Файлы кэша находятся в `mcp_server/.price_cache/` и исключены из Git. Первый поиск KNS может занять до нескольких минут из-за построения индекса карты сайта; следующие используют локальный индекс.

Предложение попадает в таблицу, только если совпали модель и **все характеристики, указанные в нашей карточке**. Варианты Pro/Plus/FE, другой объём памяти и другой заданный цвет не смешиваются. Для ноутбуков указывайте полный заводской артикул и комплектацию. Если магазин не публикует нужные параметры в доступной карточке или если собственный товар описан неоднозначно, бот сообщает причину отсутствия совпадения. Каталог НИКС просматривается в доступной категории производителя: это не гарантия полного охвата ассортимента.

Наличие определяется публичной карточкой. При нескольких подходящих вариантах выводится самая дешёвая подтверждённая карточка каждого магазина. Регион — Москва, без доставки. Сначала идёт таблица, затем совпавшие параметры, время проверки по Москве и ссылки на магазины внизу. Собственная демонстрационная цена выделяется отдельно от реальных цен конкурентов.

Для проверки добавлена демонстрационная карточка **Sony WF-1000XM5 Black**, ID **18** в первоначальной базе: модель, Bluetooth и чёрный цвет подтверждены обоими магазинами. Собственная цена 24 990 ₽ — учебная. Откройте «Каталог» → «Наушники» → эту карточку → «Сравнить с конкурентами». Наличие и цены меняются со временем.

Проверка источников без Telegram и без запуска LLM, через настоящий MCP-процесс:

```powershell
.\.venv\Scripts\python.exe -m mcp_server.check_prices --product-id 18
```

Дополнительные разрешённые YML-фиды можно добавить в массив `sources` как `{ "name": "Магазин", "url": "https://реальный-адрес/каталог.yml" }`. Для них нужны точная модель, рублёвая цена, наличие и `<param>` со всеми характеристиками нашей карточки; неизвестные параметры исключают предложение из сравнения.

## Проверка проекта

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Автоматические тесты используют временную базу и подменённые HTTP-ответы. Они проверяют права, настоящий MCP-транспорт, нормализацию памяти, модификации, наличие, выбор основной цены вместо рекомендаций, кэш и запреты robots.txt. Живая проверка запускается отдельной командой выше. Для полного сценария Telegram нужны Ollama и действующий токен. Не выкладывайте `.env`, `.venv`, кэш и `*.db` в репозиторий.
